Тест по основам JavaScript

5 заданий • максимальный балл — 10

1
Какой оператор в JavaScript выполняет строгое сравнение (без приведения типов)? Выберите один вариант ответа
Правильный ответ: ===
2
Какие из перечисленных типов данных являются примитивными в JavaScript? Выберите все правильные варианты (их несколько)
Правильные ответы: string, number, boolean
3
Какой метод массива добавляет элемент в конец массива? Выберите ответ из выпадающего списка
Правильный ответ: push()
4
Напишите название глобальной функции, которая преобразует строку в целое число. Ответ проверяется регулярным выражением, регистр не важен
Правильный ответ: parseInt()
5
Установите соответствие между методом массива и его действием. Для каждого метода выберите подходящее описание (4 пары, по 0,5 балла)
push()
pop()
shift()
unshift()
Правильные пары: push → в конец, pop → удаляет последний, shift → удаляет первый, unshift → в начало
